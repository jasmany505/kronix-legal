Política de Privacidad — Kronix Network

Última actualización: 3 de octubre de 2026

Esta Política de Privacidad explica qué información puede recopilar Kronix Network cuando utilizas sus servidores, bots, servicios, sitio web, tienda y otras funciones relacionadas.

1. Información que podemos recopilar

Dependiendo de las funciones que utilices, Kronix Network puede procesar:

  • ID de usuario de Discord.
  • Nombre de usuario y nombre visible de Discord.
  • ID del servidor, canal, rol o mensaje cuando sea necesario para proporcionar una función.
  • Información relacionada con comandos utilizados por el bot.
  • Información necesaria para administrar tickets, solicitudes, reportes, sugerencias o apelaciones.
  • Información relacionada con compras o servicios cuando sea necesaria para procesar o verificar una operación.
  • Información técnica necesaria para mantener la seguridad y funcionamiento de los Servicios.

2. Cómo utilizamos la información

La información puede utilizarse para proporcionar y mantener funciones, administrar comunidades, gestionar tickets y reportes, aplicar reglas, prevenir abusos y spam, mantener la seguridad, resolver problemas técnicos, procesar compras cuando corresponda y cumplir obligaciones legales aplicables.

3. Información de Discord

Cuando utilizas Kronix Network mediante Discord, determinadas funciones del bot pueden requerir acceso a información proporcionada por Discord. El uso de dicha información se limita a lo necesario para proporcionar las funciones del bot y se realiza de acuerdo con las políticas y condiciones aplicables de Discord.

4. Compartición de información

Kronix Network no vende información personal. La información podrá compartirse únicamente cuando sea necesario para proporcionar una función, operar los Servicios, utilizar proveedores necesarios para determinadas funciones, cumplir una obligación legal o cuando el usuario lo solicite o autorice, según corresponda.

5. Conservación de información

Conservaremos la información únicamente durante el tiempo necesario para proporcionar las funciones correspondientes, mantener la seguridad, resolver disputas, cumplir obligaciones legales o por otros motivos legítimos. Cuando ya no sea necesaria, podrá eliminarse o anonimizarse.

6. Eliminación de datos

Puedes solicitar la eliminación de información asociada a tu uso de Kronix Network cuando corresponda. Para solicitarla, contacta al equipo mediante sus canales oficiales de soporte e indica claramente que deseas solicitar la eliminación de tus datos.

7. Seguridad

Kronix Network aplica medidas razonables para proteger la información que procesa frente a accesos, modificaciones o divulgaciones no autorizadas. Ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

8. Menores de edad

Los Servicios deben utilizarse respetando las edades mínimas y demás requisitos establecidos por Discord, la legislación aplicable y las plataformas utilizadas.

9. Servicios de terceros

Kronix Network puede depender de servicios de terceros, como Discord, proveedores de alojamiento u otros servicios necesarios para proporcionar determinadas funciones. Esos terceros pueden tener sus propias condiciones y políticas de privacidad.

10. Cambios en esta Política

Podemos actualizar esta Política de Privacidad cuando sea necesario. La versión actualizada será publicada en esta misma página junto con su fecha de actualización.

11. Contacto

Si tienes preguntas sobre esta Política de Privacidad o deseas solicitar la eliminación de información, contacta al equipo de Kronix Network mediante sus canales oficiales de soporte.
